# QA Automation Projects 🚀

## 📌 Overview
This repository showcases my **QA Automation journey** using **Python + Playwright**.  
It includes structured frameworks and test suites for multiple practice websites such as **DemoBlaze** and **AutomationExercise**, covering **signup, login, product browsing, cart, checkout, and UI flows**.  

The goal is to demonstrate:
- Clean **Page Object Model (POM)** design
- **Centralized locators** (no hardcoding)
- **Reusable utilities** for test data and helpers
- **Scalable test automation practices** for real-world e-commerce flows
- **Cross-browser testing** with Playwright (Chromium, Firefox, WebKit)

---

## 🏗️ Project Architecture
QA_Automation_Projects/
│── DemoBlaze_Automation/       # Playwright framework for demoblaze.com
│── AutomationExercise/         # Practice site automation
│── locators/                   # Centralized element locators
│── pages/                      # Page classes with reusable methods
│── tests/                      # Organized test cases by feature
│── utils/                      # Config, helpers, and test data
│── reports/                    # Test execution reports (future enhancement)
│── requirements.txt            # Dependencies
│── README.md                   # Documentation


---

## 🚀 Features
- **Page Object Model (POM)** for modular design  
- **Centralized locators** to avoid duplication  
- **Reusable utilities** for configuration and test data generation  
- **Pytest integration** for structured test execution  
- **Cross‑browser support** (Chromium, Firefox, WebKit)  
- **Headed & headless execution**  
- **Scalable test coverage** across multiple practice sites  
- **Future‑ready reporting integration** (Allure/HTML)
